## 技术选择

采用 Astro 原生页面与构建期内容集合，而非在 Astro 内继续托管整站 React SPA。API 正文、导航、目录和代码高亮必须进入初始 HTML；禁用 JavaScript 后仍可阅读和导航。首页代码切换与复制使用局部、渐进增强的脚本。

调研于 2026-09-13：npm registry 的稳定版为 Astro `7.3.2`，Node 要求 `>=22.12.0`；当前本地 Node `22.23.2` 可用。锁定经安装验证的版本，保留 pnpm 锁文件，不升级无关运行库。技术依据：[Astro 7](https://astro.build/blog/astro-7/)、[构建期内容集合](https://docs.astro.build/en/guides/content-collections/)、[GitHub Pages 的 site/base 配置](https://docs.astro.build/en/guides/deploy/github/)。

路由和资源统一经过 base-path 工具：分别验证 `/` 和 `/zig-napi/` 部署，不能依赖开发服务器的 SPA fallback。Markdown 中的相对跨页链接在渲染时规范化，避免修改原始正文。未知页面返回 404，不回退为 API Overview。

依赖拆分：移除文档站的 React、Void、Tailwind 及旧 Vite 入口。WASM 浏览器验收目前直接导入 `website/node_modules/vite`，应把这个测试依赖移交 `node-test` 并改成正常包导入，验证 WASM 浏览器能力不受迁移影响。根格式化脚本必须移除已删除配置文件路径。

## kami 样式约定

依据 kami `landing-page-en.html` 的既有 token、标题、按钮、页脚与代码组件，以及设计规范中的 Documentation site 布局，移植为 Astro 共用布局。不是另行设计一套主题。

- 暖纸背景 `#f5f4ed`，浅象牙填充 `#faf9f5`；墨蓝 `#1B365D` 为唯一 UI 强调色，其余采用暖灰层级。
- 英文正文与标题使用 Charter/Georgia 衬线回退；正文 400、标题与强调 500；等宽字体只用于代码。系统 UI 字体限于导航和控件。
- 首页沿用既有内容顺序与真实素材；不编造宣传数字、图库、价格、FAQ 或截图。已有 Logo 原样保留，其固有颜色不改写为 UI token。
- 文档采用约 178px 窄侧栏与不超过约 720px 的正文阅读区。活动导航为墨蓝细轨且具有 `aria-current="page"`；分页为无卡片边框的文字链接。
- 沿用 880px/480px 断点：手机侧栏为横向滚动导航，页面本身不得横向溢出；隐藏辅助目录，表格和长代码在自身区域滚动。
- 不加入噪点、渐变背景、装饰性边线、悬浮卡片阴影和强制入场动效。所有控件有清晰键盘焦点，hover 限于支持 hover 的设备，支持 reduced motion。
- 375px 与 1280px 截图检查为硬性验收；涉及按钮另查 320px。覆盖首页、全部文档页面，并检查长文代码、表格、分页区域。

适配说明：用户要求的是文档站迁移与 kami 样式，不是商业落地页。标准营销内容 schema 的必选图库/FAQ 不适用；不填造假内容来通过该 schema。以现有 Markdown 内容清单、路由契约和产物检查作为内容中间表示与覆盖校验，保留模板视觉原语，不修改 kami 自身文件或校验器。
